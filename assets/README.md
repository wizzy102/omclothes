# Assets — drop files here

Raw Instagram screenshots are fine. I'll crop out the Instagram UI, resize and rename them in step 6.

## assets/logo/
- The brand logo, ideally `logo.png` with a transparent background.
- A screenshot of the profile picture works too if that's all there is.

## assets/products/
- 6 to 8 product photos, one product per file if possible.
- Any filenames are fine. If you know a product's name, price, sizes or colours, put them in the filename or in `products.txt` here, for example:

```
black-puffer-jacket_1850.jpg
p2.jpg = Grey Fleece Half-Zip, EGP 1100, S-XXL, grey/black
```

- If one photo is a strong wide shot of a model or outfit, name it `hero` and I'll use it as the home page banner.

Until these files exist, the site shows branded placeholders.
